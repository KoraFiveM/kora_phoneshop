# Kora Phone Shop

A FiveM map resource adding a phone shop to the Strawberry strip mall
(`sc1_11_mall2` corner unit).

## Installation

1. Place `kora_phoneshop` in your server’s resources directory.
2. Add `ensure kora_phoneshop` to your `server.cfg`.
3. Restart the server and visit the Strawberry strip mall to verify it loaded.

## Requirements

- FiveM server with `cerulean` resource support.
- Dependencies: “None”
